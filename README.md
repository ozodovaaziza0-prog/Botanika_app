# Botanika — Telegram Mini App

Клиентская часть Mini App цветочного магазина Botanika (Ташкент). Магазин продаёт охапки одного вида цветов в коробке Botanika и даёт собрать свою охапку поштучно («Собери сам»). Сейчас это кликабельный прототип на тестовых данных: каталог охапок, карточка охапки (цвет и число стеблей), «Собери сам», корзина, оформление заказа (себе / в подарок, адрес, интервалы 09:00–21:00, открытка с AI-помощником, Payme / Click / наличные), заказы и профиль. Требования — в PRD «Telegram Mini App для Botanika».

## Запуск

```bash
npm install
npm run dev            # локально в браузере
npm run build          # сборка для хостинга как Mini App (dist/)
npm run build:preview  # один HTML-файл для показа прототипа (dist-preview/)
npm run typecheck
```

## Что в прототипе ненастоящее

| Что | Сейчас | В рабочей версии |
| --- | --- | --- |
| Виды цветов, оттенки, цены за стебель, размеры охапок | `src/data.ts` | API бэкенда + админка |
| Фото охапок | SVG-иллюстрации `FlowerArt` | фото из админки |
| Подсказки адреса и карта | список адресов и схема | Google Maps Platform (или 2ГИС) |
| Цена доставки | формула «посадка + км» | API Яндекс Доставки `check-price`, формула как запасная |
| AI-помощник открытки | шаблоны `src/cardAssistant.ts` | LLM на сервере |
| Оплата | тестовая страница | Payme / Click Merchant API, статус по вебхуку |
| Заказы и статусы | в памяти страницы | бэкенд + уведомления бота |

Цвета — временные, в `:root` в `src/styles.css`; заменить на фирменные Botanika.
